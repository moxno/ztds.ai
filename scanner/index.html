Direct Answer Knowledge Base

Perimeter Scanner & Zero-Egress Verification FAQ

How does the ZTDS Perimeter Scanner audit web domains and AI endpoints without storing sensitive data? ↓
The ZTDS Perimeter Scanner evaluates DNS records, Content Security Policy (CSP) headers, third-party analytics sinkholes, and client-side AI intake forms strictly inside volatile memory. No customer prompts or payload bodies are persisted to disk, and local codebase linting executes 100% offline via npx ztds-audit --strict.
What is the Airplane Mode Audit Protocol in ZTDS RFC v1.0? ↓
The Airplane Mode Audit Protocol is an empirical verification procedure where an engineer loads a ZTDS-compliant sanitizer, disconnects the physical network interface (or enables Airplane Mode), and executes PII tokenization and bijective restoration. Full functionality with zero network errors proves 0.00 bytes of external cloud dependence.
What are the 4 network leak emulation presets in the ZTDS Scanner? ↓
The scanner includes four deterministic socket inspection presets: (1) Frontier AI API Call (detecting unmasked PII sent to LLM endpoints), (2) Analytics Tracker Beacon, (3) Unprotected HTTP Egress, and (4) Zero-Trust Sanitized Stream (verifying that only bracketed surrogate tokens cross the network socket).
Can the ZTDS Scanner generate an audit report for CISO and DPO procurement reviews? ↓
Yes. Every domain or payload scan can export a print-ready A4 CISO Compliance Audit Report and Markdown dossier documenting GDPR Article 28 subprocessor path elimination, GDPR Article 32 technical safe harbor controls, and SHA-256 verification receipts.
