The 60-Second Airplane Mode Audit

Zero-trust means you don't take our word for it. You can prove client-side isolation in any browser or terminal in 3 simple steps:

Step 1: Open DevTools

Press F12 or right-click Inspect. Switch to the Network tab and check "Preserve log".

Step 2: Turn on Airplane Mode

Disconnect your Wi-Fi or set network throttling to Offline in DevTools.

Step 3: Run Sanitizer

Run the sanitization utility. It executes completely offline with 0 failed requests and 0 bytes leaked.
