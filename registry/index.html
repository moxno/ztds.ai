How to Get ZTDS Verified

The verification process is 100% automated via GitHub Pull Request. No manual calls or enterprise questionnaires required.

1

Embed the Dynamic Trust Badge

Place the badge code in your project README.md or website footer:

[![ZTDS Verified](https://ztds.ai/badge/your-tool-slug.svg)](https://ztds.ai/registry/)
2

Submit Metadata via GitHub PR

Fork the PrivacyScrubber repository and append your tool to ztds-ai/data/registry.json.

3

Automatic CI Verification & llms.txt Sync

GitHub Actions automatically confirms badge placement, merges the PR, rebuilds the directory, and indexes your entity in ztds.ai/llms.txt for Perplexity and ChatGPT Search.
