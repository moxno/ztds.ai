01. Tri-Partite Legal Architecture

Our governance strictly separates the public specification text, open-source reference implementations, and verified certification trust marks.

Pillar 01

Specification Text

The formal text of the ZTDS specification, RFC documents, and mathematical proofs are published under Creative Commons Attribution 4.0 International (CC-BY-4.0).

  • Free to read, copy, translate, and implement globally.
  • Mandatory academic citation to ZTDS Consortium and author DOIs.
  • Immutable version archival on Zenodo, OSF, and CERN.
Pillar 02

Reference Engine & SDK

Official test suites, verification CLIs, and reference SDK engines are dual-licensed under the Apache License, Version 2.0.

  • Commercial and enterprise use permitted without royalty.
  • Express grant of patent rights from all consortium contributors.
  • Patent retaliation termination protection built in.
Pillar 03

Trust Mark Governance

The name "ZTDS", "Zero-Trust Data Sanitization", and the ZTDS Verified™ seal are protected certification trade marks.

  • Display permitted ONLY for products with active cryptographic registry receipts.
  • Revocable if an implementation violates Invariant 1 (Egress).
  • No recoloring, distortion, or unauthorized co-branding permitted.

02. RAND-Z Patent Non-Assertion Covenant

The ZTDS AI Consortium enforces a Reasonable and Non-Discriminatory with Zero Royalty (RAND-Z) patent covenant modeled after the World Wide Web Consortium (W3C) Patent Policy.

Irrevocable Covenant Terms

"Each Participant, Fellow, and Corporate Sponsor irrevocably pledges that it will not assert against any Implementer any Essential Claims owned or controlled by the Participant, for the making, using, selling, offering for sale, or importing of any compliant Implementation of a Ratified ZTDS Specification, provided that such Implementation complies with all Normative Requirements set forth in RFC-8821."
