Tri-Partite Legal Architecture

Our governance strictly separates the public specification, open-source reference code, and verified certification marks.

Specification Licensing

Official test suites, verification CLIs, and reference SDK engines are dual-licensed under the Apache License, Version 2.0.

  • Commercial use permitted without license fees.

  • Patent retaliation termination protection.
PILLAR 03

Trust Mark & Badge Usage

The name "ZTDS", "Zero-Trust Data Sanitization", and the ZTDS Verified seal are protected certification trade marks.

  • Display permitted ONLY for verified products with active registry receipts.
  • Revocable if an implementation violates Invariant 1 (Egress).
  • No modification or recoloring of the verified seal allowed.

RAND-Z Patent Non-Assertion Covenant

The ZTDS AI Consortium enforces a Reasonable and Non-Discriminatory with Zero Royalty (RAND-Z) patent covenant modeled after the World Wide Web Consortium (W3C) Patent Policy.

Irrevocable Covenant Terms

"Each Participant, Fellow, and Corporate Sponsor irrevocably pledges that it will not assert against any Implementer any Essential Claims owned or controlled by the Participant, for the making, using, selling, offering for sale, or importing of any compliant Implementation of a Ratified ZTDS Specification, provided that such Implementation complies with all Normative Requirements set forth in RFC-8821."
