Direct Answer Knowledge Base

Interactive Zero-Trust Pipeline Inspector FAQ

What does the ZTDS Pipeline Inspector simulate in the browser? ↓
The Pipeline Inspector executes a live four-stage Directed Acyclic Graph (DAG) inside browser volatile memory: (1) Raw Prompt Ingestion, (2) Deterministic In-RAM Surrogate Tokenization, (3) Simulated Cloud LLM Reasoning over synthetic tokens, and (4) Local Bijective Restoration.
Does the Pipeline Inspector transmit test prompts to any backend server or external LLM API? ↓
No. Every stage of the Pipeline Inspector runs 100% locally in your browser JavaScript heap with 0.00 bytes of network egress. You can verify this by opening browser DevTools Network inspection or enabling Airplane Mode while testing.
How does the Inspector demonstrate Theorem 2 volatile memory zeroization? ↓
During simulation, the Inspector displays the active ephemeral tokenMap holding surrogate-to-entity pairs in RAM. Clicking Flush Memory or completing the session immediately zeroizes all map entries, proving that zero residual PII persists in memory or storage.
How can developers integrate the inspected DAG pipeline into production Node.js or Python apps? ↓
Developers can copy the generated four-line integration blueprint using the open reference package (@ztds/core or ztds-python) or deploy the certified commercial engine (@privacyscrubber/sdk and @privacyscrubber/mcp-server) for 30 specialized industry profiles.
