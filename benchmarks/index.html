Technical FAQ & Methodology

Frequently Asked Questions on AI DLP & Sanitization Benchmarks

How does In-RAM ZTDS latency compare to Cloud DLP proxies and local NLP containers? ↓
ZTDS In-RAM sanitization executes deterministically inside local process memory with a median p50 latency of 42.8 microseconds (< 0.1 milliseconds) and p99 latency under 0.3 milliseconds. By contrast, heavy local Python NLP containers add 85 to 190 milliseconds per prompt, and SaaS Cloud DLP proxies add 240 to 450 milliseconds of WAN round-trip lag while introducing GDPR Article 28 subprocessor liability.
What is the Leakage Prevention Rate (LPR) across GPT-4o, Claude 3.7 Sonnet, Gemini 2.0 Pro, and OpenAI o3? ↓
Across all 30 multi-domain enterprise and multimodal benchmark scenarios (118 sensitive entities spanning HIPAA, PCI-DSS, GLBA, DevSecOps secrets, FRE 502 legal privilege, HR records, and SIEM logs), ZTDS achieves a 100.00% Leakage Prevention Rate with 0.00 bytes of cleartext egress prior to socket transmission across all six evaluated frontier model families.
Why does context-preserving surrogate tokenization outperform static asterisk redaction in LLM reasoning? ↓
Static irreversible redaction (replacing values with [REDACTED] or ****) destroys coreference resolution and breaks code or JSON syntax, degrading LLM reasoning accuracy. ZTDS assigns typed bijective surrogate tokens ([EMAIL_TOKEN_1], [IBAN_TOKEN_1], [NAME_TOKEN_2]), achieving a 100.00% Context Preservation Score (CPS) and 100.00% Bijective Fidelity Score (BFS) during local response restoration.
How are multimodal visual documents and OCR bounding boxes evaluated in the ZTDS benchmark? ↓
The benchmark includes five high-resolution multimodal scenarios (BENCH-MM-01 through BENCH-MM-05) covering clinical intake forms, KYC identity documents, cloud architecture diagrams, legal exhibits, and executive contracts. Conformance requires solid pixel burn-in with 6px safety padding in local canvas memory prior to vision model ingestion, verified via SHA-256 frame receipts.
How can engineering teams run the ZTDS benchmark locally against their own prompts and models? ↓
Engineers can execute the offline deterministic benchmark suite directly from any terminal via npx ztds-bench --strict, export a formal Markdown CISO evaluation dossier with --out-report benchmark-report.md, or mint an Ed25519 cryptographically signed conformance certificate with the --cert flag without transmitting source files externally.
